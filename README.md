# Tabentic Recipes

Ready-to-use prompts ("recipes") for **[Tabentic](https://www.tabentic.com)**, the AI agent that works inside your Chrome tabs. Copy a recipe, open the page you want help with, and paste it into Tabentic. Reading tasks run right away; anything that clicks, types or submits shows you the plan first and waits for your approval.

- Website: https://www.tabentic.com
- Chrome extension: https://chromewebstore.google.com/detail/mflkmacalibfeiopafmehigedobihcjg
- Free plan, no account needed. Pro has a 7-day free trial, no card.

## How to use a recipe

1. Install the Tabentic Connector extension and open https://www.tabentic.com/app
2. Open the website you want help with in another tab and pick it in Tabentic
3. Paste a recipe below (edit the parts in [brackets]) and run it

## Reading recipes (never click anything)

| Recipe | Prompt |
|---|---|
| Summarize a page | Summarize this page in 5 short bullet points, then one sentence on what matters most for me. |
| Explain like I'm new | Explain this page in plain language for someone new to the topic. List any terms I should look up. |
| Pull contact info | List every name, email, phone number and address on this page in a table. |
| Table to CSV | Turn the main table on this page into CSV I can paste into Google Sheets. |
| Compare two products | Compare the products in my two selected tabs in a table: price, key specs, shipping, return policy, and which is better for [my use]. |
| Find broken links | List links on this page that look broken, empty or point to the wrong place. |
| Check for errors | Check this page for typos, broken layout text, missing images and confusing wording. List fixes. |
| Pricing breakdown | Extract every plan and price on this page into a table with what each plan includes. |
| Job post check | Summarize this job post: pay, location/remote, must-have skills, red flags, and 3 questions I should ask. |
| Review sentiment | Read the reviews on this page and give me the top 3 praises, top 3 complaints and an overall verdict. |
| Research notes | Turn this article into study notes: key points, numbers, quotes worth keeping, and open questions. |
| Recipe shopping list | Turn the recipe on this page into a grouped shopping list for [number] servings. |

## Action recipes (shows a plan, waits for your approval)

| Recipe | Prompt |
|---|---|
| Fill a form from notes | Fill the form on this page using these details: [paste your details]. Do not submit. |
| Draft a reply | Draft a clear, friendly reply to the email open in this tab that [what you want to say]. Put it in the reply box but do not send. |
| Save listings to a sheet | Copy the title, price and link of every listing on this page into my Google Sheet tab, one row each. |
| Bulk-tag items | On this page, add the tag [tag] to every item that matches [rule]. Show me the list first. |
| Weekly check | Open each of my selected tabs, note anything new since last week, and give me a short summary. |

Tabentic always asks before high-risk steps such as payments, sending messages, deleting anything or entering passwords.
